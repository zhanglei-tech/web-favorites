# 大模型知识问答平台操作

# 创建知识库

点击菜单中的【知识库】按钮，打开知识库管理页面。

点击右上角的【新建】按钮，新建一个知识库。

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image.png)

输入知识库名称，索引模型选择m3e，文件处理模型选择glm4，点击【确认创建】按钮

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%201.png)

在右上角的【新建/导入】中选择【文本数据集】

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%202.png)

来源选择【本地文件】

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%203.png)

上传本地文件，点击下一步

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%204.png)

根据文档内容选择训练模式和处理方式，也可保持默认值，点击下一步

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%205.png)

点击【开始上传】按钮

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%206.png)

系统自动开始创建知识库索引，等文件状态变为“已就绪”就已经创建完毕

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%207.png)

# 创建知识库问答应用

在应用中新建一个应用

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%208.png)

输入应用名称，类型选择【知识库+对话引导】，确认创建

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%209.png)

修改AI模型为glm4，选择关联知识库

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%2010.png)

可以关联多个知识库

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%2011.png)

点击发布按钮，保存修改，即可在对话中引用知识库中的知识进行对话

![image.png](../attachment/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E7%9F%A5%E8%AF%86%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0%E6%93%8D%E4%BD%9C/image%2012.png)
