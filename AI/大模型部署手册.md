## 安装docker

### 下载docker、docker compose安装包

docker下载地址

```jsx
https://download.docker.com/linux/static/stable/x86_64/docker-27.3.1.tgz
```

docker compose下载地址

```jsx
https://github.com/docker/compose/releases/download/v2.30.3/docker-compose-linux-x86_64
```

### 解压docker安装包

```jsx
tar -xzvf docker-27.3.1.tgz
```

### 将解压之后的`docker`文件移到 `/usr/bin`目录下

```jsx
cp docker/* /usr/bin/
```

### 将`docker`注册成系统服务

```jsx
vim /etc/systemd/system/docker.service
```

在文件中添加以下内容，退出并保存

```jsx
[Unit]
Description=Docker Application Container Engine
Documentation=https://docs.docker.com
After=network-online.target firewalld.service
Wants=network-online.target

[Service]
Type=notify
ExecStart=/usr/bin/dockerd
ExecReload=/bin/kill -s HUP $MAINPID
LimitNOFILE=infinity
LimitNPROC=infinity
TimeoutStartSec=0
Delegate=yes
KillMode=process
Restart=on-failure
StartLimitBurst=3
StartLimitInterval=60s

[Install]
WantedBy=multi-user.target

```

给文件增加可执行权限

```jsx
chmod +x /etc/systemd/system/docker.service
systemctl daemon-reload 
```

设置开机自启动

```jsx
systemctl enable docker
```

### 安装docker compose plugin

```jsx
mkdir -p /usr/local/lib/docker/cli-plugins
chmod +x docker-compose-linux-x86_64
cp docker-compose-linux-x86_64 /usr/local/lib/docker/cli-plugins/docker-compose
```

### 启动docker

```jsx
systemctl start docker
```

### 检查docker状态

```jsx
docker info
```

```bash

```


## 启动对话大模型

### CPU启动

```bash
docker run -d -v /opt/ollama:/root/.ollama -p 11434:11434 --restart=always --name ollama --network docker_fastgpt ollama/ollama
```

--network参数后跟fastgpt使用的网络名，确保对话大模型跟对话框架使用同一网络

### GPU启动

```bash
docker run -d --gpus=all -v /opt/ollama:/root/.ollama -p 11434:11434 --restart=always --name ollama --network docker_fastgpt ollama/ollama
```

### 切换CPU、GPU运行

先删除正在运行的容器

```bash
docker stop ollama
docker rm ollama
```

再执行CPU/GPU相应的启动命令
