# Web Favorites Collection 🌐

一个技术收藏夹仓库，包含开发、运维、系统配置等各类技术文档和实用链接的集合。

## 📁 目录结构

1. **Git** - 版本控制与部署
2. **Linux** - 服务器运维
3. **MacOS** - 苹果系统配置
4. **Windows** - Windows 系统
5. **业务知识** - 企业系统理解
6. **开发技术** - 编程与技术栈
7. **开发环境** - 环境配置
8. **群辉** - NAS 与 Docker

## 🎯 项目目标

本仓库旨在收集和整理常用的技术文档、配置指南和最佳实践，方便快速查阅和学习。内容涵盖：

- **开发部署**：自动化部署、版本控制、持续集成
- **系统运维**：服务器监控、性能调优、故障处理
- **开发环境**：多平台环境配置、工具链搭建
- **企业系统**：工业软件架构、业务系统理解
- **个人技术栈**：日常开发中的实用技巧和解决方案

## 🔄 使用方式

### 克隆仓库
```bash
git clone https://github.com/zhanglei-tech/web-favorites.git
```

### 贡献指南
1. 发现有价值的技术文章或实用文档
2. 按照分类创建或更新相应的 Markdown 文件
3. 提交 Pull Request 或直接推送更新
